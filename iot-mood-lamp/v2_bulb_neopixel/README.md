# V2 — 전구 + 네오픽셀 무드등

V1(릴레이 전구)에 **네오픽셀 링을 소켓 흰 고리 위에 얹어**, 앱·음성으로 **색과 밝기**까지 바꾸는 버전입니다.
전구는 밝은 조명, 네오픽셀은 갓을 물들이는 무드 조명을 맡습니다.

> 📌 **상태: 준비 단계** — 단계 폴더마다 목표·확인 방법을 먼저 적어 두었고, 코드는 차례로 채웁니다.
> **V1을 먼저 완성한 뒤** 진행하세요. 릴레이·센서 코드는 V1 것을 그대로 가져옵니다.

## 구성

| 부품 | 핀 | 역할 | V1 대비 |
|---|:---:|---|:---:|
| ESP32 WROOM-32 DevKit | — | 두뇌 + 와이파이 | 같음 |
| 릴레이 (5V 1채널, 절연형) | **GPIO26** | 220V 전구 켜기/끄기 | 같음 |
| 인체감지센서 (PIR) | **GPIO25** | 사람이 있는지 | 같음 |
| 조도센서 | **GPIO34** | 주변이 어두운지 | 같음 |
| **네오픽셀 RGBW 링** | **GPIO27** | 색·밝기 무드 조명 | **추가** |
| 전원 | — | 220V(램프 코드) + **5V 2A 어댑터** → [`../docs/power.md`](../docs/power.md) | **1A → 2A** |

배선 → **[`wiring.md`](wiring.md)**

## 전구와 네오픽셀의 역할 나누기 (초안)

| 상황 | 전구 | 네오픽셀 |
|---|:---:|---|
| 앱·음성 '켜' / '꺼' | 켜짐 / 꺼짐 | 켜짐 / 꺼짐 (함께) |
| 앱에서 전구만 · 네오픽셀만 | 개별 제어 | 개별 제어 |
| 색 바꾸기 · 밝기 슬라이더 | 변화 없음 | 색·밝기 변경 |
| 자동 모드에서 켜질 때 | 켜짐 | 마지막 색으로 서서히 켜짐 |

> 전구 밝기는 릴레이로 조절할 수 없습니다(켜기/끄기만). **'밝게/어둡게'는 네오픽셀에만** 적용됩니다.
