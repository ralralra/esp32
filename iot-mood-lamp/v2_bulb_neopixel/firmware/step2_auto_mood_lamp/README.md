# V2 · 2단계 — 자동 무드등 + 네오픽셀 (와이파이 없이)

> ⏳ 준비 중 — 코드(`step2_auto_mood_lamp.ino`)는 이 폴더에 추가 예정

## 목표
[V1 3단계 자동 무드등](../../../v1_relay_bulb/firmware/step3_auto_lamp/)에 네오픽셀을 합쳐,
자동으로 켜질 때 **전구 + 네오픽셀(마지막 색)** 이 함께 켜지게 한다.

## 설계 포인트
- V1 3단계 코드를 복사해 시작 — 릴레이·센서 부분은 손대지 않는다
- **서서히 켜기/끄기(페이드)** 도 `millis()` 로 — `delay()` 를 쓰면 센서 판단이 멈춘다
- 조도센서가 **네오픽셀 빛**까지 보지 않는지 다시 확인 (V1보다 빛이 하나 늘었다)
- 시리얼 명령 추가: `c 255 120 0`(색) · `b 50`(밝기 %) · `bulb on/off` · `led on/off`

## 확인
- [ ] 자동으로 켜질 때 전구와 네오픽셀이 함께 켜짐
- [ ] 시리얼로 색·밝기를 바꾼 뒤 껐다 켜도 마지막 색 유지
- [ ] 네오픽셀을 켜도 조도센서 값 때문에 꺼지지 않음
