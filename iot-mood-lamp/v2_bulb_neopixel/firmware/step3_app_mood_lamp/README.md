# V2 · 3단계 — 앱·음성 연동 완성 펌웨어

> ⏳ 준비 중 — 코드(`step3_app_mood_lamp.ino`)는 이 폴더에 추가 예정

## 목표
2단계에 [V1 4단계](../../../v1_relay_bulb/firmware/step4_app_lamp/)의 통신 부분을 얹고,
**색·밝기 명령**까지 처리한다.

## 설계 포인트
- 명령·상태 이름은 [`../../apps_script/README.md`](../../apps_script/README.md) 의 약속을 그대로
- 색 값은 미리 정한 이름(`warm`, `red` …)과 6자리 색 코드(`FF8800`) 둘 다 받기
- 밝기 명령이 연달아 와도 **마지막 값만** 적용 (슬라이더 대비)
