# V2 배선 — 전구 + 네오픽셀

릴레이·인체감지·조도센서와 **220V 쪽 배선은 V1과 같습니다** → [`../v1_relay_bulb/wiring.md`](../v1_relay_bulb/wiring.md)
여기서는 **추가되는 네오픽셀과 바뀌는 전원**만 다룹니다.

## 네오픽셀 배선

| 네오픽셀 핀 | 연결 | 이유 |
|---|---|---|
| **DIN** | **300~500Ω 저항** → ESP32 **GPIO27** (D1 R32: D6) | 신호선 보호 (첫 LED 손상 방지) |
| **5V** | 5V 2A 어댑터 **+** | 보드를 거치지 않고 어댑터에서 직접 |
| **GND** | 어댑터 **−** 그리고 ESP32 GND | **GND 공통** — 빠지면 엉뚱한 색 |
| 5V–GND 사이 | **1000µF 커패시터** (+극 → 5V) | 전원 켤 때 순간 전류 흡수 |

- 신호선은 **짧게.** 링이 소켓 위에 있으므로 받침 안 보드에서 소켓까지의 거리만큼만.
- 네오픽셀 신호는 3.3V이고 규격상 기준(5V 전원일 때 약 3.5V)보다 살짝 낮습니다.
  대부분 동작하지만 색이 튀거나 깜빡이면 **74AHCT125 레벨시프터**를 넣습니다.
- 링은 흰 고리 위에 얹고, **소켓 쪽 열이 직접 닿지 않게** 내열 양면테이프나 실리콘으로 고정합니다 (LED 전구 사용).

## 전원 — V1과 달라지는 점

네오픽셀 전류가 크기 때문에 **보드의 USB를 거치지 않고 어댑터에서 바로** 나눠 줍니다.

```
[5V 2A 어댑터] ─┬─ 5V ──▶ 네오픽셀 5V   (1000µF 커패시터)
                ├─ 5V ──▶ ESP32 VIN      ← 완성 후에만 연결 (아래 참고)
                ├─ 5V ──▶ 릴레이 VCC, PIR VCC
                └─ GND ─▶ 모든 GND 공통
[220V 콘센트] ──램프 코드──▶ 릴레이 접점 ──▶ 전구     (V1과 같음, 교사 작업)
```

| 시기 | ESP32 전원 | 네오픽셀·릴레이·PIR 전원 |
|---|---|---|
| **개발 중** (코드 업로드) | PC **USB** | 어댑터 5V — **VIN에는 연결하지 않음**, GND만 공통 |
| **완성 후** | 어댑터 5V → **VIN** (USB 뽑음) | 어댑터 5V |

> **USB와 어댑터 5V를 VIN에 동시에 넣지 않습니다.** 보드에 따라 역류 보호가 없어 PC USB 포트나 어댑터가 상할 수 있습니다.
