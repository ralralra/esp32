# V1 · 1단계 — 릴레이 테스트

> ⏳ 준비 중 — 코드(`step1_relay_test.ino`)는 이 폴더에 추가 예정

## 목표
시리얼 모니터에서 `1`/`0`을 입력하면 릴레이가 붙었다 떨어지는지 확인한다.

## 진행
1. **220V 연결 없이** 릴레이만 연결 → 딸깍 소리와 릴레이 모듈의 LED로 확인
2. 산 릴레이가 LOW에서 켜지는지(active-LOW) HIGH에서 켜지는지 기록 → 이후 코드의 상수로 사용
3. (교사) 220V 전구 배선 후 실제 점등 확인 → [`../../wiring.md`](../../wiring.md)

## 확인
- [ ] `1` → 딸깍 + 모듈 LED 켜짐 / `0` → 딸깍 + 꺼짐
- [ ] 보드 리셋(EN 버튼) 순간에 릴레이가 붙지 않음
- [ ] 트리거 방식 기록: active-LOW / active-HIGH
