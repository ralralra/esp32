# V1 · 2단계 — 조도·인체감지 센서 읽기

> ⏳ 준비 중 — 코드(`step2_sensors.ino`)는 이 폴더에 추가 예정

## 목표
조도값(0~4095)과 인체감지(0/1)를 시리얼에 1초마다 찍고, **자동 켜기 기준값**을 실측으로 정한다.

## 진행
1. 교실 불 켰을 때 / 껐을 때 / 손으로 센서를 가렸을 때 조도값을 기록
2. 램프를 켰을 때 조도값이 **변하지 않는 위치**를 찾아 센서 고정 (램프 빛이 닿으면 켜짐↔꺼짐 반복)
3. PIR 앞에서 움직였다 멈췄다 하며 감지 유지 시간 확인 (전원 직후 수십 초는 불안정)

## 기록표
| 상황 | 조도값 |
|---|:---:|
| 교실 불 켬 | |
| 교실 불 끔 | |
| 램프 켬 (센서 위치 확인용) | |
| → 켜는 기준값 / 끄는 기준값 (서로 다르게) | / |
