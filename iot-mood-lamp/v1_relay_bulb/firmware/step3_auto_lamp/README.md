# V1 · 3단계 — 자동 무드등 (와이파이 없이)

> ⏳ 준비 중 — 코드(`step3_auto_lamp.ino`)는 이 폴더에 추가 예정

## 목표
센서만으로 **어둡고 사람이 있으면 켜고, 일정 시간 아무도 없으면 끄는** 무드등을 완성한다.

## 설계 포인트
- **논블로킹**: `delay()` 대신 `millis()`로 시간을 잰다 (4단계에서 통신을 얹어도 멈추지 않게)
- **히스테리시스**: 켜는 기준값과 끄는 기준값을 다르게 → 경계값에서 깜빡임 방지
- **상수로 빼기**: 기준값·자동 꺼짐 시간을 코드 위쪽에 모아 둔다
- **시리얼 명령**: `on` / `off` / `auto` / `s`(상태) — 앱 없이 시험·시연 가능

## 확인
- [ ] 어두운 상태에서 PIR 앞을 지나가면 켜짐
- [ ] 자리를 비우고 설정 시간이 지나면 꺼짐
- [ ] 밝은 곳에서는 사람이 있어도 켜지지 않음
- [ ] 램프가 켜진 뒤 자기 빛 때문에 꺼지지 않음
