# V1 · 4단계 — 앱·음성 연동 완성 펌웨어

> ⏳ 준비 중 — 코드(`step4_app_lamp.ino`)는 이 폴더에 추가 예정

## 목표
3단계 자동 무드등에 **와이파이 + 중계서버 폴링**을 얹어, 앱 버튼·음성으로 제어하고 상태를 앱에 보여준다.

## 설계 포인트
- 1~1.5초마다 `?mode=next` 로 새 명령 확인 → 실행 → `?mode=report` 로 상태 보고
- 명령·상태 이름은 [`../../apps_script/README.md`](../../apps_script/README.md) 의 약속을 **글자 하나까지** 그대로
- 와이파이가 끊겨도 자동 모드와 시리얼 명령은 계속 동작 (통신은 덤)
- 통신이 느려도 센서 판단이 밀리지 않게 통신을 별도 작업(ESP32의 다른 코어)으로 분리
