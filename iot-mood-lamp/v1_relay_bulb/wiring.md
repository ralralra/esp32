# V1 배선 — 릴레이 전구

## ⚠️ 가장 중요한 것 하나

**220V 배선(전구 ↔ 릴레이)은 교사가 직접 합니다.** 학생은 아래 '저전압 배선'까지만 작업합니다.

## 저전압 배선 (학생 작업)

| 부품 | 부품 핀 | ESP32 DevKit 핀 | (D1 R32 라벨) | 이유 |
|---|---|:---:|:---:|---|
| 릴레이 | IN | **GPIO26** | D2 | 부팅에 관여하지 않는 일반 출력 핀 |
| 릴레이 | VCC / GND | VIN(5V) / GND | — | 릴레이 코일은 5V |
| 인체감지(PIR) | OUT | **GPIO25** | D3 | 디지털 입력 |
| 인체감지(PIR) | VCC / GND | VIN(5V) / GND | — | HC-SR501은 5V 전원, 출력은 3.3V라 그대로 연결 가능 |
| 조도센서 | AO | **GPIO34** | A3 | ADC1 — 와이파이를 켜도 아날로그 읽기 가능 |
| 조도센서 | VCC / GND | **3V3** / GND | — | 출력이 3.3V를 넘지 않도록 |

## 전원

```
[5V 1A 충전기] ──USB──▶ ESP32 DevKit ── VIN(5V) ──▶ 릴레이 VCC, PIR VCC
                                     ── 3V3 ─────▶ 조도센서 VCC
                                     ── GND ─────▶ 모든 GND 공통
[220V 콘센트] ──램프 코드──▶ 릴레이 접점 ──▶ 전구     (교사 작업, 아래)
```

V1은 전류가 적어 **DevKit의 USB 포트로 전원을 넣고, VIN 핀에서 5V를 꺼내 쓰면** 됩니다.
(USB 연결 시 VIN 핀에 5V가 나옵니다. 보드에 따라 다이오드 때문에 약간 낮을 수 있음)

## 220V 쪽 (교사 작업)

```
콘센트 ── L(활선) ──▶ 릴레이 COM ── NO ──▶ 소켓 ──▶ 전구
       ── N(중성선) ─────────────────────────▶ 소켓
```

- **활선(L) 한 가닥만** 릴레이로 끊어 잇습니다. 중성선은 그대로 둡니다.
- **NO(평상시 열림)** 단자를 써서 ESP32가 꺼지거나 리셋되면 전구도 꺼지게 합니다.
- 릴레이 단자는 케이스나 수축튜브로 **완전히 덮어** 손이 닿지 않게 합니다.
- 램프 코드의 중간 스위치는 남겨 둡니다 — 비상시 수동으로 끌 수 있게.

## 피해야 할 핀

| 핀 | 이유 |
|---|---|
| GPIO 0 · 2 · 12 · 15 | 부팅 모드에 영향 (부팅·업로드 실패 원인) |
| GPIO 1 · 3 | USB 시리얼(업로드·시리얼 모니터) |
| GPIO 6~11 | 내부 플래시 메모리 전용 — 절대 사용 금지 |
| ADC2 핀 (GPIO 2·4·12~15·25~27 등) | 와이파이를 켜면 **아날로그 읽기 불가** (디지털 용도는 괜찮음) |
| GPIO 34·35·36·39 | **입력 전용** — 센서 읽기만 가능, 출력 불가 |

## 코드에서 주의할 점

**부팅 순간 전구가 깜빡이지 않게:** active-LOW 릴레이(LOW에서 켜짐)라면 `pinMode` 보다 **먼저** 끈 상태를 써 둡니다.

```cpp
digitalWrite(RELAY_PIN, HIGH);   // 먼저 '꺼짐' 값을 써 두고
pinMode(RELAY_PIN, OUTPUT);      // 그다음 출력으로 전환
```
