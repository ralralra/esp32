# V1 — 릴레이 전구 무드등

기존 전구를 **릴레이로 켜고 끄는** 버전입니다.
앱 버튼·음성으로 켜고 끄고, 어두워지면 자동으로 켜지고 사람이 없으면 자동으로 꺼집니다.

> 📌 **상태: 준비 단계** — 단계 폴더마다 목표·확인 방법을 먼저 적어 두었고, 코드는 차례로 채웁니다.

## 구성

| 부품 | 핀 | 역할 |
|---|:---:|---|
| ESP32 WROOM-32 DevKit | — | 두뇌 + 와이파이 |
| 릴레이 (5V 1채널, 절연형) | **GPIO26** | 220V 전구 켜기/끄기 |
| 인체감지센서 (PIR) | **GPIO25** | 사람이 있는지 |
| 조도센서 | **GPIO34** | 주변이 어두운지 |
| 전원 | — | 220V(램프 코드) + **5V 1A 충전기**(USB) → [`../docs/power.md`](../docs/power.md) |

배선 → **[`wiring.md`](wiring.md)**

## 동작 규칙 (초안)

| 모드 | 켜지는 조건 | 꺼지는 조건 |
|---|---|---|
| **자동** (기본) | 어두움 **그리고** 사람 감지 | 사람이 일정 시간(예: 5분) 감지 안 됨 |
| **수동** | 앱·음성 '켜' | 앱·음성 '꺼' |

- 앱이나 음성으로 켜기/끄기를 하면 **수동 모드**로 바뀌고, '자동' 명령으로 다시 자동 모드로 돌아갑니다.
- 시간·기준값은 코드 위쪽 상수로 빼 두어 3단계에서 실측으로 정합니다.
