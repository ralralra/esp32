# V1 · 2단계 — 출력 테스트 (네오픽셀 스트립 16구)

> ✅ 코드: [`step2_neopixel_test.ino`](step2_neopixel_test.ino) — ESP32 컴파일 확인 완료
> 라이브러리: **Adafruit NeoPixel** (라이브러리 관리에서 설치)

## 목표
스트립만 연결해 **색 순서 · 밝기 · 웜화이트** 가 제대로 나오는지 확인한다.

## 진행
1. 배선 → [`../../wiring.md`](../../wiring.md). **SEL 점퍼를 빼고 EXT PWR에 5V** (PC USB만 꽂으면 네오픽셀에 전원이 안 감)
2. 업로드하면 **빨강 → 초록 → 파랑** 순서로 스트립 전체가 한 색으로 켜졌다가 웜화이트(주황빛)로 켜진 채 멈춘다.
   - 시리얼에 찍히는 이름과 실제 색이 다르면 `LED_RGBW` 설정을 스트립에 맞춘다.
   - **초록·빨강·파랑·꺼짐이 한 칸씩 번갈아** 켜져 있으면 RGB 스트립에 RGBW 데이터를 보낸 것 → `LED_RGBW = false`
   - 끝쪽 LED가 안 켜지거나 앞쪽만 켜지면 `LED_COUNT`를 자른 개수에 맞춘다
3. 시리얼(115200)로 색·밝기를 바꿔 본다: `c red` · `c FF8800` · `c rainbow` · `b 30` · `off` · `on` · `test`
4. 밤에 램프를 켜 두고 **조명으로 충분히 밝은지** 본다. 어두우면 `MAX_BRIGHTNESS`를 올리고 EXT PWR 쪽 포트를 3A 이상으로.

## 확인
- [ ] 첫 LED부터 16번째까지 모두 **같은 색**으로 켜짐 (`LED_COUNT = 16`, `LED_RGBW = false`)
- [ ] 빨강이 빨강으로 나옴 (색 순서)
- [ ] `c warm`(주황빛 흰색)이 `c white`보다 따뜻하게 보임
- [ ] 흰색 최대 밝기(`b 100`)에서 보드가 리셋되지 않음
