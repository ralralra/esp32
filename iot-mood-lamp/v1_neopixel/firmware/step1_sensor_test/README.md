# V1 · 1단계 — 센서 테스트 (조도 + 인체감지)

> ✅ 코드: [`step1_sensor_test.ino`](step1_sensor_test.ino) — ESP32 컴파일 확인 완료 · V2와 같은 코드

## 목표
조도센서 값(원시값 0~4095 · 밝기 %)과 PIR(0/1)을 시리얼로 보며 **어두움 기준 `DARK_LEVEL`** 을 정한다.

## 진행
1. 업로드 → 시리얼 모니터(115200). 1초마다 이렇게 찍힌다.
   ```
   조도 원시값=2890  밝기= 70%  → 밝음   → 꺼짐 (기준 30%)  |  PIR=0  마지막 감지 12초 전
     PIR ▲ 감지됨
   조도 원시값= 830  밝기= 20%  → 어두움 → 켜짐 (기준 30%)  |  PIR=1  마지막 감지 0초 전
   ```
2. **손으로 센서를 가린다** → 밝기 %가 **내려가야** 정상. 올라가면 `DARK_IS_HIGH = true`로 바꿔 다시 업로드.
3. 교실 불 켬 / 끔 / 커튼 침 — 각각 밝기 %를 적는다.
4. '켜졌으면' 하는 상황과 '꺼졌으면' 하는 상황 사이의 숫자를 **`DARK_LEVEL`** 로 정한다 (예: 불 켬 70%, 불 끔 15% → 30).
5. PIR 앞에서 움직였다 멈춘다 — `▲ 감지됨`이 뜨는지, 몇 초 뒤 `▽ 해제`되는지 보고 모듈 다이얼(감도·유지시간)을 맞춘다.
