# V2 · 1단계 — 네오픽셀 링 테스트

> ⏳ 준비 중 — 코드(`step1_neopixel_test.ino`)는 이 폴더에 추가 예정

## 목표
링 하나만 연결해 **색 · 밝기 · 웜화이트(W 채널)** 가 제대로 나오는지 확인한다.

## 진행
1. Arduino IDE 라이브러리 관리자에서 **Adafruit NeoPixel** 설치
   - LED 개수는 **24** (`LED_COUNT = 24`, 24구 링)
2. RGBW 링이면 `NEO_GRBW + NEO_KHZ800`, RGB 링이면 `NEO_GRB + NEO_KHZ800`
3. 빨강 → 초록 → 파랑 → 흰색(W) 순서로 켜 보기 — **색 순서가 다르면 GRBW/RGBW 설정 문제**
4. `setBrightness()` 로 최대 밝기 상한 정하기 (어댑터 용량 안에서)

## 확인
- [ ] 첫 LED부터 마지막 LED까지 모두 켜짐 (LED 개수 설정 확인)
- [ ] 빨강이 빨강으로 나옴 (색 순서 설정 확인)
- [ ] 웜화이트가 RGB 혼합 흰색보다 따뜻하게 보임
- [ ] 최대 밝기 흰색에서도 ESP32가 리셋되지 않음
- [ ] **조명으로 쓰기에 충분히 밝은가** — 밤에 램프를 켜 두고 판단. 어두우면 LED 수를 늘리고 어댑터 용량도 다시 계산
