# V2 · 2단계 — 자동 무드등 (와이파이 없이)

> ✅ 코드: [`step2_auto_mood_lamp.ino`](step2_auto_mood_lamp.ino) — PC 시뮬레이터로 시나리오 검증 완료 ([`sim/`](../../../sim/README.md), `make run`)
> 조도 기준값·릴레이 방향 등 코드 위쪽 상수는 실측 후 바꾸세요.

## 목표
[V1 3단계 자동 무드등](../../../v1_relay_bulb/firmware/step3_auto_lamp/)의 **릴레이 자리를 네오픽셀로 바꿔**,
어둡고 사람이 있으면 마지막 색으로 서서히 켜지고, 아무도 없으면 서서히 꺼지게 한다.

## 설계 포인트
- V1 3단계 코드를 복사해 시작 — 센서 판단 부분은 그대로, `digitalWrite(릴레이)` 자리만 네오픽셀 켜기/끄기로
- **서서히 켜기/끄기(페이드)** 도 `millis()` 로 — `delay()` 를 쓰면 센서 판단이 멈춘다
- 조도센서가 **네오픽셀 빛**을 보지 않는 위치인지 다시 확인
- 시리얼 명령: `on` / `off` / `auto` / `s`(상태) / **`sensor`**(센서 값 1초마다 표시, 다시 입력하면 끔) + `c 255 120 0`(색) · `c warm`(색 이름) · `b 50`(밝기 %)

## 센서 값 확인 — 기준값 정하기

업로드한 뒤 시리얼 모니터(115200)에 **`sensor`** 를 입력하면 1초마다 이렇게 찍힙니다.

```
[센서] 조도=2890 ( 70%) 밝음    기준: 켜짐≤1200 꺼짐≥1500 | PIR=0 마지막 감지 12s 전
[센서] PIR 감지됨 ▲
[센서] 조도= 830 ( 20%) 어두움  기준: 켜짐≤1200 꺼짐≥1500 | PIR=1 마지막 감지 0s 전 | 자동 꺼짐까지 300s
```

| 할 일 | 보는 값 | 바꿀 상수 |
|---|---|---|
| 교실 불 켬 / 끔 / 센서 가림 — 각각 조도값 기록 | `조도=` 원시값 | `DARK_ON_LEVEL`(이보다 어두우면 켬) · `DARK_OFF_LEVEL`(이보다 밝으면 끔, ON보다 크게) |
| 램프를 켠 채로 조도값이 **변하지 않는 위치** 찾기 | 램프 켜기 전후 `조도=` 차이 | 센서 위치 (값이 뛰면 램프 빛이 들어오는 것) |
| PIR 앞에서 움직였다 멈추기 | `PIR 감지됨 ▲` / `해제 ▽`, `마지막 감지 ns 전` | PIR 모듈의 감도·유지시간 다이얼 |
| 조도 모듈이 어두울수록 값이 **커지면** | 불을 끄는데 값이 올라감 | `DARK_IS_HIGH = true` |

PIR은 전원을 넣고 **30~60초**는 값이 불안정하니 그 뒤에 보세요.

## 확인
- [ ] 어두운 상태에서 PIR 앞을 지나가면 마지막 색으로 서서히 켜짐
- [ ] 자리를 비우고 설정 시간이 지나면 서서히 꺼짐
- [ ] 시리얼로 색·밝기를 바꾼 뒤 껐다 켜도 마지막 색 유지
- [ ] 네오픽셀이 켜져도 조도센서 값 때문에 꺼지지 않음
