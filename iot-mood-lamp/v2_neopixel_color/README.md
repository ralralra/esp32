# V2 — 네오픽셀 컬러 무드등

220V 전구 대신 **5V 네오픽셀이 조명 전체를 맡는** 버전입니다.
앱·음성으로 켜기/끄기뿐 아니라 **색과 밝기**까지 바꾸고, 센서 자동 동작은 V1과 같습니다.

> 📌 **상태: 준비 단계** — 단계 폴더마다 목표·확인 방법을 먼저 적어 두었고, 코드는 차례로 채웁니다.
> 센서·통신 코드는 V1 것을 그대로 가져오고, **릴레이 자리를 네오픽셀로 바꾸는** 구조입니다.

## V1과 무엇이 다른가

| 항목 | V1 릴레이 전구형 | **V2 네오픽셀 컬러형** |
|---|---|---|
| 학습 목표 | 릴레이를 이용한 전원 제어 | **LED의 색·밝기 제어** |
| 조명 | 기존 220V 전구 | **5V 네오픽셀** |
| 켜기·끄기 | 가능 (릴레이) | 가능 (코드로 LED 끄기) |
| 색 변경 | 없음 | **가능** |
| 밝기 조절 | 없음 | **가능** |
| 센서 | 조도 + PIR | 동일 |
| 음성제어 | 전원·모드 | **전원·모드·색·밝기** |
| 전원 플러그 | 2개: 전구(220V) + 5V | **1개: 5V 2A 어댑터** |
| 220V 작업 | 있음 (교사) | **없음 — 학생이 전부 배선 가능** |

## 구성

| 부품 | 핀 | 역할 |
|---|:---:|---|
| ESP32 WROOM-32 DevKit | — | 두뇌 + 와이파이 |
| **네오픽셀 RGBW 링** (또는 스트립) | **GPIO27** | 조명 전체 — 색·밝기 |
| 인체감지센서 (PIR) | **GPIO25** | 사람이 있는지 (V1과 같음) |
| 조도센서 | **GPIO34** | 주변이 어두운지 (V1과 같음) |
| 전원 | — | **5V 2A 어댑터 하나** → [`../docs/power.md`](../docs/power.md) |

배선 → **[`wiring.md`](wiring.md)**

> 💡 네오픽셀 하나로 방을 밝히는 조명이 되므로 **밝기가 충분한지** 1단계에서 꼭 확인하세요.
> 16구 링이 어둡다면 24구 링이나 스트립으로 LED 수를 늘리고, 그만큼 어댑터 용량도 키웁니다.

## 동작 규칙 (초안)

| 상황 | 네오픽셀 |
|---|---|
| 앱·음성 '켜' / '꺼' | 마지막 색·밝기로 켜짐 / 꺼짐 (수동 모드로 전환) |
| 색 바꾸기 · 밝기 슬라이더 · "밝게/어둡게" | 색·밝기 변경 |
| 자동 모드: 어두움 + 사람 감지 | 마지막 색으로 **서서히** 켜짐 |
| 자동 모드: 일정 시간 사람 없음 | 서서히 꺼짐 |
