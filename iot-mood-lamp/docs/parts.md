## 네오픽셀 — WS2812B RGB 스트립 16구 (V1)

V1에서는 네오픽셀이 **조명 전체**를 맡습니다. 쓰는 부품은 **WS2812B(5050) RGB 스트립**을 **16구**로 잘라 소켓 둘레에 감은 것입니다.
링과 달리 지름을 맞출 필요가 없고, 빛이 옆(주름 갓 쪽)으로 퍼져 갓 전체가 은은하게 물듭니다.

### 코드 설정 — 스트립에 맞춰야 함
| 상수 | 값 | 이유 |
|---|---|---|
| `LED_COUNT` | **16** | 자른 LED 개수. 다르면 끝이 안 켜지거나 앞쪽만 켜짐 |
| `LED_RGBW` | **false** | WS2812B는 LED당 3바이트(G·R·B). `true`(4바이트)로 보내면 **초록·빨강·파랑·꺼짐이 한 칸씩 번갈아** 켜지는 증상 |

### 흰색은 섞어서 만든다
RGB 스트립에는 흰색 칩이 따로 없어서, 코드의 `warm`은 (255,170,80)으로 섞은 **주황빛 흰색**, `white`는 (255,255,255)입니다.
더 따뜻하거나 차가운 흰색을 원하면 `c FF9050` 처럼 6자리 색 코드로 직접 정합니다.
(흰색 칩이 따로 있는 **RGBW(SK6812)** 스트립·링으로 바꾸면 `LED_RGBW = true`)

### 자르기·붙이기
- 스트립은 **가위 표시(⌁)가 있는 구리 패드 사이**에서만 자릅니다. 16구 = 60구/m 스트립 약 27cm.
- 화살표(→) 방향이 데이터 흐름입니다. **보드에서 나온 DIN 선은 화살표가 시작되는 쪽** 패드에 납땜합니다.
- 소켓 둘레에 감을 때 너무 급하게 꺾으면 LED가 떨어집니다. 지름 3cm 이하로는 감지 않습니다.

### 전류
흰색 최대 밝기에서 LED 1개당 약 60mA (Adafruit 가이드의 경험칙) → **16구면 약 1A**.
코드의 `MAX_BRIGHTNESS = 128`(절반)로 **약 0.5A**로 묶고, 전원은 보드를 거치지 않고 실드 EXT PWR로 넣습니다. → [`power.md`](power.md)

## 릴레이 — KY-019형 5V 1채널 (V2)

사용 모듈: **TONGLING JQC-3FF-S-Z 5VDC** 릴레이가 올라간 KY-019형 (검은 기판, 핀 `S · + · −`).

| 항목 | 내용 |
|---|---|
| 코일 | 5V — 실드 V 핀(보드 5V)으로 바로 구동 |
| 트리거 | **HIGH** (신호를 주면 켜짐) → 펌웨어 `RELAY_ACTIVE_LOW = false` |
| 3.3V 신호 | 트랜지스터를 직접 켜는 구조라 ESP32의 3.3V로 여유 있게 동작 |
| 접점 | 10A 250VAC — 220V LED 전구에 충분 |
| 포토커플러 | **없음** → 220V 단자 쪽 절연(수축튜브·케이스)을 꼭 할 것 |

> 릴레이 본체에 `12VDC`라고 적힌 모듈은 보드 5V로 켜지지 않으니 쓰지 않습니다.
> LOW 트리거(VCC·GND·IN, LED 2개) 모듈은 ESP32의 3.3V에서 꺼지지 않는 경우가 있어 권하지 않습니다.
> **SSR(무접점)은 비추천.** 꺼진 상태에서도 누설 전류로 LED 전구가 희미하게 켜져 있을 수 있습니다.

## 센서

| 센서 | 연결 | 주의 |
|---|---|---|
| 조도 (LDR 모듈) | 아날로그 AO → **실드 A3 (GPIO34)**, VCC는 **3V3** | 램프 자기 빛이 닿으면 켜짐↔꺼짐을 반복 → 빛이 안 닿는 곳에 두기. 이번 모듈은 **어두울수록 원시값이 커짐**(`DARK_IS_HIGH = true`) — 다른 모듈이면 1단계에서 확인 |
| 인체감지 PIR (HC-SR501) | 디지털 OUT → **실드 3번 (GPIO25)**, VCC 5V | 라탄·플라스틱 너머는 잘 못 봄 → **렌즈를 받침 밖으로 노출**. 전원 직후 30~60초는 불안정. 감도·유지시간 다이얼 2개 |

> 더 정확한 밝기(lux) 값이 필요하면 I2C 조도센서(BH1750)로 바꿀 수 있습니다 — 이 경우 GPIO21(SDA)·22(SCL) 사용.
