# 보드 — ESP32 DevKit(30핀) + 확장 베이스보드

이 프로젝트는 **ESP32 DevKit 30핀**을 **확장 베이스보드**에 꽂아서 씁니다.
베이스보드는 GPIO 핀마다 **G·V·S 3핀 헤더**가 있어서, 센서 모듈을 **브레드보드 없이 바로 꽂을 수 있습니다.**

## 베이스보드 구성

| 위치 | 이름 | 하는 일 |
|---|---|---|
| 위 왼쪽 | **DC 잭 (6.5~16V)** | 어댑터 전원 입력 — 보드 안 레귤레이터가 5V로 바꿈 |
| 위 오른쪽 | **USB5V (USB-C)** | 5V 전원 입력 — 휴대폰 충전기를 꽂는 곳 |
| 위 가운데 | **전압 점퍼 (3V / 5V JUMP)** | 모든 G·V·S 헤더의 **V 핀 전압**을 3.3V 또는 5V로 선택 |
| 위 오른쪽 아래 | **5V · 3.3V · GND 전원 헤더** | 전압이 다른 부품에 전원을 따로 줄 때 |
| 위 왼쪽 아래 | **GND · VCC · D21 · D22** | I2C 부품용 (이 프로젝트에서는 안 씀) |
| 양옆 | **G·V·S 헤더 13줄씩** | 바깥쪽부터 **S(신호) · V(전원) · G(GND)** — 줄 옆에 GPIO 번호가 인쇄됨 |
| 가운데 | ESP32 DevKit | 코드 업로드는 DevKit의 USB로 |

## 이 프로젝트에서 쓰는 헤더 (모두 오른쪽 줄)

| 부품 | 꽂는 줄 | V1 | V2 |
|---|:---:|:---:|:---:|
| 네오픽셀 링 | **D27** | — | ✅ |
| 릴레이 | **D26** | ✅ | — |
| 인체감지(PIR) | **D25** | ✅ | ✅ |
| 조도센서 | **D34** (V선만 3.3V 헤더로 — 아래 참고) | ✅ | ✅ |

## 전압 점퍼는 5V로

| 부품 | 필요한 전원 | 점퍼 5V일 때 |
|---|---|---|
| 릴레이 (5V 코일) | 5V | ✅ 그대로 |
| PIR (HC-SR501) | 5V (출력은 3.3V) | ✅ 그대로 |
| 네오픽셀 | 5V | ✅ 그대로 |
| **조도센서 (아날로그)** | **3.3V** | ⚠ **V선만 따로** 3.3V 헤더에 |

**왜 조도센서만 다른가:** 조도센서 모듈은 받은 전압 범위 안에서 값을 내보냅니다.
V에 5V를 주면 출력이 3.3V를 넘을 수 있고, ESP32 입력 핀은 3.3V까지만 견딥니다.
그래서 조도센서는 **G·S는 D34 줄에, V는 위쪽 전원 헤더의 3.3V 핀에** 각각 **암-암 점퍼선**으로 꽂습니다.

## 꽂기 전에 확인할 것

- **핀 순서**: 베이스보드는 바깥쪽부터 **S·V·G**입니다. 센서 모듈은 제품마다 순서가 달라서(예: `VCC·GND·OUT`, `- + S`)
  3핀 케이블을 통째로 꽂으면 전원이 거꾸로 들어갈 수 있습니다. **모듈 핀 이름과 헤더의 S·V·G를 한 가닥씩 맞춰** 꽂으세요.
- **전압 점퍼 위치**: 점퍼를 바꾼 뒤에는 V 핀 전압을 멀티미터로 한 번 확인합니다 (제품마다 표기 방식이 다를 수 있음).
- **전원은 하나만**: 코드 업로드할 때는 DevKit USB(PC)만, 완성 후에는 베이스보드 USB-C(어댑터)만 연결합니다.
  두 곳에 동시에 전원을 넣으면 제품에 따라 전원이 거꾸로 흐를 수 있습니다.
- **D34·D35·VP(36)·VN(39)는 입력 전용** — 센서 읽기만 됩니다. 릴레이·네오픽셀은 꽂지 마세요.
