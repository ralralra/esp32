# 전원 — 왜 플러그가 2개인가

## 결론

**전구 버전(V1)이든 네오픽셀 버전(V2)이든 전원은 2개입니다.**
네오픽셀 때문에 전원이 하나 더 생기는 게 아니라, **전구(220V)와 ESP32(5V)가 처음부터 다른 전기**를 쓰기 때문입니다.
네오픽셀을 추가하면 달라지는 건 전원 **개수**가 아니라 **5V 어댑터의 용량**입니다.

| | 전원 ① 220V 교류 (램프 원래 코드) | 전원 ② 5V 직류 (어댑터) |
|---|---|---|
| **V1 릴레이·전구** | 전구 | ESP32 · 릴레이 코일 · 센서 → **5V 1A 휴대폰 충전기면 충분** |
| **V2 전구+네오픽셀** | 전구 | ESP32 · 릴레이 코일 · 센서 · **네오픽셀** → **5V 2A 어댑터** |

## 왜 하나로 안 되나

```
220V 콘센트 ──[램프 코드]──▶ 릴레이(스위치) ──▶ 전구          ← 전구는 220V 교류로만 켜짐
5V 어댑터  ──[USB/DC]─────▶ ESP32 · 릴레이 코일 · 센서 · 네오픽셀 ← 전자회로는 5V/3.3V 직류
```

- **릴레이는 전원이 아니라 '스위치'** 입니다. ESP32의 5V 쪽 작은 신호로, 220V 쪽 선을 붙였다 뗐다 할 뿐
  두 전기는 서로 섞이지 않습니다(포토커플러로 절연된 모듈을 쓰는 이유).
- 220V를 ESP32에 그대로 넣을 수 없고, 5V로는 220V 전구를 켤 수 없습니다.
- 그래서 **콘센트에 꽂히는 플러그가 2개**가 됩니다 → 멀티탭 하나에 둘 다 꽂으면 됩니다.

## 왜 V2는 2A가 필요한가

네오픽셀은 흰색 최대 밝기에서 LED 1개당 약 60mA를 씁니다(Adafruit 가이드의 경험칙).
16구 링이면 네오픽셀만 1A 가까이 되고, 여기에 와이파이를 쓰는 ESP32와 릴레이 코일이 더해집니다.
1A 충전기로는 밝은 흰색에서 **ESP32가 리셋되거나 색이 이상해질 수 있어** 2A를 권합니다.
코드에서 `setBrightness()` 로 최대 밝기를 제한하면 여유가 더 생깁니다.

## 플러그를 1개로 줄이고 싶다면

| 방법 | 장점 | 주의 |
|---|---|---|
| **멀티탭에 플러그 2개** (권장) | 220V를 건드리는 부분이 릴레이뿐 — 가장 안전·단순 | 선이 2가닥 |
| 220V→5V **내장형 AC-DC 모듈**을 램프 코드에서 분기 | 플러그 1개, 완성도 높아 보임 | **220V 배선이 하나 더 늘어남 → 교사 작업.** 모듈 용량(V2는 2A급)과 절연·발열 확인 필수 |
| 전구를 빼고 **네오픽셀(RGBW 웜화이트)이 조명 전체를 담당** | 5V 하나로 끝, 220V·릴레이 불필요 → 학생이 전부 작업 가능 | 백열/LED 전구만큼 밝지는 않음. 이 경우 릴레이 단계는 생략 |

> 수업·박람회에서는 **멀티탭 + 플러그 2개**를 기본으로 하고,
> 완성도를 더 올리고 싶을 때 교사가 내장형 모듈을 검토하는 순서를 권합니다.
