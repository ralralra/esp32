# 전원 — V1은 플러그 1개, V2는 2개

## 결론

| | 220V 교류 (램프 원래 코드) | 5V 직류 | 플러그 |
|---|---|---|:---:|
| **V1 네오픽셀** | 사용 안 함 (전구 빼고 코드 분리) | 보드 + **네오픽셀** + 센서 → **2포트 USB 충전기 (2.4A 포트 + 1A 포트)** | **1개** |
| **V2 릴레이 전구** | 전구 | 보드 · 릴레이 코일 · 센서 → **5V 1A 휴대폰 충전기면 충분** | **2개** |

## V1 — 네오픽셀은 EXT PWR로

V1은 **조명 자체를 5V 네오픽셀이 맡기** 때문에 220V가 필요 없습니다.
다만 네오픽셀 전류가 커서 보드(micro USB → 레귤레이터 → 5V 핀)를 거치지 않고, 센서쉴드의 **EXT PWR 단자**로 따로 넣습니다.

```
2포트 USB 충전기 ──① micro USB ──▶ Wemos D1 R32 (보드 · 조도센서 3V3)
  (플러그 1개)    ──② USB 전원선 ──▶ 실드 EXT PWR ──▶ 디지털 줄 V ──▶ 네오픽셀, PIR   (SEL 점퍼 뺌)
```

- 소켓의 **전구는 빼고, 램프의 220V 코드는 분리**합니다. 빈 소켓에 220V가 들어오는 일을 원천 차단하기 위해서입니다.
- 220V 작업이 없으므로 **학생이 배선 전부를 직접** 할 수 있습니다.

### 왜 2A 이상인가

네오픽셀은 흰색 최대 밝기에서 LED 1개당 약 60mA를 씁니다(RGB 기준, Adafruit 가이드의 경험칙).
**16구 스트립**이면 최대 밝기에서 약 1A, 여기에 와이파이를 쓰는 ESP32(약 0.24A)가 더해집니다.
펌웨어는 `MAX_BRIGHTNESS = 128`(절반)로 네오픽셀을 **약 0.5A**로 묶습니다. LED를 더 늘리면 그만큼 커집니다.

| 포트 | 쓰는 것 | 최대 전류 | 포트 용량 |
|---|---|---|---|
| ① 보드 micro USB | ESP32 + 조도센서 | 약 0.3A | 1A 포트 |
| ② EXT PWR | 네오픽셀 16구(상한 128) + PIR | 약 0.5A | **2A 이상 포트** (2.4A 포트의 약 20%, 상한 255로 올려도 약 1A) |

→ 흔한 **'2.4A + 1A' 2포트 충전기**면 됩니다. 2.4A 쪽을 EXT PWR에, 1A 쪽을 보드에. 16구는 상한을 255까지 올려도 2.4A 포트 안에 들어옵니다. LED를 30구 이상으로 늘리면 **3A 이상** 포트가 필요합니다.

## V2 — 전구는 220V, 보드는 5V

```
220V 콘센트 ──[램프 코드]──▶ 릴레이(스위치) ──▶ 전구          ← 전구는 220V 교류로만 켜짐
5V 충전기  ──[micro USB]──▶ 보드 ──▶ 릴레이 코일 · 센서       ← 전자회로는 5V/3.3V 직류 (SEL 점퍼 꽂음)
```

- **릴레이는 전원이 아니라 '스위치'** 입니다. ESP32의 작은 신호로 220V 쪽 선을 붙였다 뗐다 할 뿐, 두 전기는 섞이지 않습니다.
- 220V를 보드에 그대로 넣을 수 없고, 5V로는 220V 전구를 켤 수 없습니다. 그래서 **플러그가 2개** → 멀티탭 하나에 둘 다 꽂습니다.
- 릴레이 코일(약 70~90mA) + PIR + 조도센서 + ESP32 → **1A 충전기**로 충분합니다.

> 플러그를 1개로 줄이려면 220V→5V 내장형 모듈을 램프 코드에서 분기하는 방법이 있지만,
> 220V 배선이 하나 더 늘어나므로 **교사 작업**이며 절연·발열 확인이 필수입니다. 제작·시연에서는 멀티탭을 권합니다.
