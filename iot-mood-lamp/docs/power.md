# 전원 — V1은 플러그 2개, V2는 1개

## 결론

| | 전원 ① 220V 교류 (램프 원래 코드) | 전원 ② 5V 직류 (어댑터) | 플러그 |
|---|---|---|:---:|
| **V1 릴레이 전구형** | 전구 | ESP32 · 릴레이 코일 · 센서 → **5V 1A 휴대폰 충전기면 충분** | **2개** |
| **V2 네오픽셀 컬러형** | 사용 안 함 (전구 빼고 코드 분리) | ESP32 · 센서 · **네오픽셀** → **5V 2A 어댑터** | **1개** |

## 왜 V1은 하나로 안 되나

```
220V 콘센트 ──[램프 코드]──▶ 릴레이(스위치) ──▶ 전구          ← 전구는 220V 교류로만 켜짐
5V 어댑터  ──[USB]────────▶ ESP32 · 릴레이 코일 · 센서         ← 전자회로는 5V/3.3V 직류
```

- **릴레이는 전원이 아니라 '스위치'** 입니다. ESP32의 5V 쪽 작은 신호로 220V 쪽 선을 붙였다 뗐다 할 뿐,
  두 전기는 서로 섞이지 않습니다.
- 220V를 ESP32에 그대로 넣을 수 없고, 5V로는 220V 전구를 켤 수 없습니다.
- 그래서 **콘센트에 꽂히는 플러그가 2개** → 멀티탭 하나에 둘 다 꽂으면 됩니다.

> 플러그를 1개로 줄이려면 220V→5V 내장형 모듈을 램프 코드에서 분기하는 방법이 있지만,
> 220V 배선이 하나 더 늘어나므로 **교사 작업**이며 절연·발열 확인이 필수입니다. 제작·시연에서는 멀티탭을 권합니다.

## 왜 V2는 하나로 되나

V2는 **조명 자체를 5V 네오픽셀이 맡기** 때문에 220V가 필요 없습니다.

```
5V 2A 어댑터 ──USB-C──▶ 베이스보드 5V ──┬──▶ 네오픽셀 (조명)
   (플러그 1개)                         ├──▶ ESP32 DevKit
                                      └──▶ PIR · 조도센서(3.3V 헤더)
```

- 소켓의 **전구는 빼고, 램프의 220V 코드는 분리**합니다. 빈 소켓에 220V가 들어오는 일을 원천 차단하기 위해서입니다.
- 220V 작업이 없으므로 **학생이 배선 전부를 직접** 할 수 있습니다.

## 왜 V2는 2A가 필요한가

네오픽셀은 흰색 최대 밝기에서 LED 1개당 약 60mA를 씁니다(RGB 기준, Adafruit 가이드의 경험칙).
**24구 링**이면 최대 밝기에서 네오픽셀만 1.4A가 넘고(RGBW는 W까지 켜면 1.9A 가까이), 여기에 와이파이를 쓰는 ESP32(약 0.24A)가 더해집니다.
1A 충전기로는 밝은 흰색에서 **ESP32가 리셋되거나 색이 이상해질 수 있어** 2A를 권합니다.
펌웨어는 `MAX_BRIGHTNESS = 128`(절반)로 네오픽셀을 **약 1A 이하**로 묶어, 전체 약 1.2A → 2A 어댑터의 60% 선에서 씁니다.
밝기 상한을 255까지 올리고 싶으면 **5V 3A** 어댑터로 바꿉니다.

- RGBW 링은 W(흰색) 칩까지 모두 켜면 이보다 더 쓸 수 있으므로, 코드에서 `setBrightness()` 로 최대 밝기를 제한합니다.
- 조명으로 쓰기에 어두워서 **LED 수를 늘리면 어댑터 용량도 그만큼 키웁니다** (대략 LED 수 × 60mA + ESP32 여유분).
