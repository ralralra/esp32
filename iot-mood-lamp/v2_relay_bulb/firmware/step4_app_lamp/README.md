## 동작
- 자동 모드는 3단계와 같은 규칙. 앱 자동화 탭의 **어두움 기준 %·꺼지는 시간**은 보드에 저장돼 껐다 켜도 유지
- 2초마다 서버에서 **내 팀 명령**을 하나씩 가져와 실행 — `ON` · `OFF` · `AUTO` · `CONFIG` (`COLOR`·`BRIGHT`는 무시)
- 켜짐·모드·설정이 바뀌면 바로, 움직임은 5초에 한 번까지, 그 밖에는 30초마다 상태 보고 (`type=bulb`)
- 통신은 **다른 코어**에서 돌아서, 와이파이가 느리거나 끊겨도 자동 켜기·끄기는 계속

## 시리얼 모니터 (115200)
`on` · `off` · `auto` · `s`(상태) · `n`(서버 연결 확인 — 응답 코드와 원인)
