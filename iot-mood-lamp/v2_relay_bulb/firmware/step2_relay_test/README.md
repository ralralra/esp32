# V2 · 2단계 — 출력 테스트 (릴레이)

> ✅ 코드: [`step2_relay_test.ino`](step2_relay_test.ino) — ESP32 컴파일 확인 완료

## 목표
시리얼로 릴레이를 붙였다 떼며 '딸깍' 소리와 모듈 LED를 확인한다.

## 진행
1. **220V 연결 없이** 릴레이만 실드 2번에 꽂는다 → [`../../wiring.md`](../../wiring.md). SEL 점퍼 꽂음.
2. 업로드 → 시리얼(115200)에 `1`(켜기) · `0`(끄기) · `t`(토글) · `blink`(3번)
3. 보드 **리셋 버튼**을 눌러 본다 — 리셋 순간 릴레이가 붙으면 안 된다.
4. (교사) 220V 전구 배선 후 실제 점등 확인.

## 확인
- [ ] `1` → 딸깍 + 모듈 LED 켜짐 / `0` → 딸깍 + 꺼짐
- [ ] 리셋 순간에 릴레이가 붙지 않음
- [ ] HIGH 신호에서 켜지고 LOW에서 꺼짐 (KY-019형) — 반대면 `RELAY_ACTIVE_LOW = true`
