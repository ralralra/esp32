# V2 · 3단계 — 센서 받고 출력하기 (자동 전구, 와이파이 없이)

> ✅ 코드: [`step3_auto_lamp.ino`](step3_auto_lamp.ino) — 동작 검증·ESP32 컴파일 확인 완료
> **1단계에서 정한 `DARK_LEVEL` · `DARK_IS_HIGH` 를 코드 위쪽에 똑같이 적으세요.**

## 목표
1단계 센서 코드 + 2단계 릴레이 코드를 합쳐, **기준보다 어두우면 켜지고 밝아지면 꺼지는** 전구를 완성한다.

## 규칙
| 상황 | 동작 |
|---|---|
| 밝기 < `DARK_LEVEL` 그리고 움직임 | 켜짐 |
| 밝기 ≥ `DARK_LEVEL` + 5% | 꺼짐 (밝아짐) |
| 움직임 없이 `AUTO_OFF_MS`(5분) | 꺼짐 (사람 없음) |
| `USE_PIR = false` | PIR 없이 조도만으로 켜고 끔 |

## 설계 포인트
- **논블로킹**: `delay()` 없이 `millis()`로 — 4단계에서 통신을 얹어도 멈추지 않게
- **여유 5%**(`DARK_MARGIN`): 경계에서 릴레이가 딸깍거리지 않게
- 조도센서가 **전구 빛을 보지 않는 위치**인지 확인 — 자기 빛을 보면 켜짐↔꺼짐 반복

## 시리얼 (115200)
`on` · `off` · `auto` · `s`(상태) · **`sensor`**(센서 값 1초마다, 다시 입력하면 끔)

## 확인
- [ ] 어두운 상태에서 PIR 앞을 지나가면 켜짐
- [ ] 불을 켜면(밝아지면) 꺼짐
- [ ] 자리를 비우고 5분 지나면 꺼짐
- [ ] 램프가 켜진 뒤 자기 빛 때문에 꺼지지 않음 (센서 위치)
