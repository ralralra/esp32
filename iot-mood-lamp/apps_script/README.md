# 중계 서버 — 구글 시트 1개로 12팀 (Apps Script)

**선생님이 한 번만** 만들고, 반 전체(TEAM01 ~ TEAM12)가 같은 주소를 같이 씁니다.
학생은 펌웨어의 `TEAM_ID`만 자기 팀 번호로 바꾸면 됩니다.

```
[학생 앱 12개] ─┐                          ┌─ [ESP32 무드등 12대]
  ?mode=set     │                          │   ?mode=next   (2초마다 내 팀 명령 꺼내기)
  ?mode=state   ├──▶  mood_lamp.gs  ◀──────┤   ?mode=report (바뀔 때 + 30초마다)
  ?mode=teams   │     (시트 1개)            │
                └──────────────────────────┘
```

## 만들기 (선생님, 10분)

1. 구글 드라이브 → **새 스프레드시트** (이름 예: `IoT 무드등 — 1학년 3반`)
2. 메뉴 **확장 프로그램 → Apps Script** → 기본 코드를 지우고 [`mood_lamp.gs`](mood_lamp.gs) 전체 붙여넣기 → 저장
3. 위쪽 함수 목록에서 **`setupSheets`** 선택 → **실행** → 권한 허용
   → 시트에 `state`(TEAM01~TEAM12 12행)와 `log` 탭이 생깁니다
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행: **나** · 액세스 권한: **모든 사용자**
   - 배포 → 나오는 URL(끝이 **`/exec`**)을 복사
5. 이 URL을 학생들에게 나눠 줍니다 → 펌웨어의 `SERVER_URL`, 앱 프롬프트의 `[웹앱 URL]`에 넣기
6. 브라우저에서 `URL?mode=teams` 를 열어 12팀 목록이 나오면 성공

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다.
> 새 배포를 만들면 URL이 바뀌니, 같은 배포를 '새 버전'으로 갱신하세요.

## 주소 약속 (앱 · ESP32 · 서버 공통)

모든 요청에 **`team=TEAM01`** ~ **`TEAM12`** 가 들어갑니다 (`teams` 제외).

| 누가 | 요청 | 응답 |
|---|---|---|
| 앱 | `?mode=set&team=TEAM01&cmd=ON` | `{"ok":true,...}` |
| 앱 | `?mode=state&team=TEAM01` | 아래 상태 JSON + `online` · `age`(초) |
| 앱 | `?mode=teams` | `{"teams":[{"team":"TEAM01","online":true,"type":"bulb"}, …]}` |
| ESP32 | `?mode=next&team=TEAM01` | `{"cmd":"COLOR","value":"warm"}` / 없으면 `{"cmd":""}` |
| ESP32 | `?mode=report&team=TEAM01&type=..&power=..&…` | `{"ok":true}` |

### 명령 (`cmd`)

| cmd | value | 뜻 | V1 전구 | V2 네오픽셀 |
|---|---|---|:---:|:---:|
| `ON` / `OFF` | — | 켜기 / 끄기 (수동 모드로) | ✅ | ✅ |
| `AUTO` | — | 자동 모드로 | ✅ | ✅ |
| `COLOR` | `warm` `white` `red` `orange` `yellow` `green` `blue` `purple` `pink` `rainbow` 또는 `FF8800` | 색 | 무시 | ✅ |
| `BRIGHT` | `0`~`100` | 밝기 % | 무시 | ✅ |
| `CONFIG` | — (`dark=0~100`, `off=10~3600` 따로) | 어두움 기준 % · 자동 꺼짐 초 | ✅ | ✅ |

- 같은 종류 명령이 쌓이면 **마지막 것만** 남깁니다 (켜기·끄기·자동은 한 종류로 봄) — 슬라이더 연타 대비
- **10분** 동안 아무도 안 가져간 명령은 버립니다 — 나중에 켠 보드가 엉뚱하게 동작하지 않게

### 상태 (`report`로 보내고 `state`로 읽음)

| 이름 | 값 | 비고 |
|---|---|---|
| `type` | `bulb` / `neopixel` | 앱이 이걸 보고 화면 1·2를 고름 |
| `power` | `ON` / `OFF` | |
| `auto` | `1` 자동 / `0` 수동 | |
| `color` · `bright` | 색 이름·코드 · 0~100 | 네오픽셀만 |
| `light` | **주변 밝기 0~100%** (클수록 밝음) | 조도 모듈 값을 보드에서 %로 바꿔 보냄 |
| `motion` | `1` 감지 / `0` 없음 | 시트에는 기록하지 않음 |
| `dark` · `off` | 어두움 기준 % · 자동 꺼짐 초 | 자동화 탭에 표시 |
| `online` | `true` / `false` | 서버가 계산 — 40초 넘게 보고가 없으면 `false` |

## 12팀이 함께 쓸 때

- 빠르게 바뀌는 값(명령 대기열·현재 상태)은 **캐시(CacheService)** 에 두고, 시트에는
  **바뀐 값만**(또는 1분에 한 번) 적습니다. 12대가 2초마다 물어도 시트 쓰기가 몰리지 않게 하기 위해서입니다.
- 캐시가 지워져도 상태는 `state` 탭에서 다시 읽고, 대기 중이던 명령만 사라집니다(앱에서 다시 누르면 됨).
- `log` 탭에는 **명령만** 남습니다. 인체감지(재실) 정보는 기록하지 않습니다.
- 수업 중 반응이 눈에 띄게 느려지면 펌웨어의 `POLL_MS`(2000)를 3000으로 늘리세요.
  Apps Script에는 동시 실행 수 등 할당량이 있어, 요청이 많을수록 응답이 늦어질 수 있습니다.

## 테스트 (PC에서)

```bash
node iot-mood-lamp/apps_script/test/gs_test.js
```

구글 시트·캐시·잠금을 흉내 내 `mood_lamp.gs`를 그대로 실행합니다 — 팀 분리, 명령 합치기, 10분 만료,
CONFIG 범위 제한, 캐시가 지워졌을 때 시트에서 복구, 재실 정보 미기록 등 24가지를 확인합니다.
