# Lavender Deck — 디자인 규격

참고 덱("4시간 뒤, 앱개발자 탄생")에서 뽑은 값. `scripts/deck.js`의 상수와 같다.

## 색 (hex, `#` 없이)

| 역할 | 값 | 어디에 |
|---|---|---|
| 배경 | `F7F4FB` | 모든 슬라이드. 어두운 배경 슬라이드는 없음 (표지·마무리도 밝게) |
| 진남색 `dk1` | `1F1442` | 제목, 본문 강조, 코드 바 채움, "따라 하기" 태그, 체크 원 |
| 회보라 `dk2` | `6E6591` | 부제, 설명문, 바닥글 |
| 연보라 `lt2` | `EFEAFB` | 표 줄무늬, 칩 바탕, 폰 목업 안 상자 |
| 보라 `accent1` | `5038A6` | 섹션 라벨, 번호 원, 강조 단어, "실습 · 20분" 태그, 콜아웃 글씨, 강조 카드 채움 |
| 주황 `accent2` | `F2A03D` | 강조 배너·카드 하나, 두 번째 트랙(V2) 뱃지. 한 장에 한 덩어리만 |
| 테두리/콜아웃 `accent6` | `DDD8F7` | 흰 카드 테두리(1pt), 콜아웃 채움, 표지 알약 |
| 청록·장미·파랑 | `2A9D8F` `E0567A` `3D7FD9` | 아이콘 색 변주용. 넓은 면에는 쓰지 않음 |
| 경고 | 채움 `FDECEA` · 선 `F5C6C0` · 글 `9A1C12` | 안전·합선 등 꼭 읽어야 하는 상자 |

비율: 배경 연보라 60~70%, 흰 카드 20~30%, 보라·진남색 포인트 10%, 주황은 한 장에 한 번.

## 글꼴

- 본문·제목: **Noto Sans KR** (없으면 맑은 고딕으로 대체됨)
- 코드·명령어: **JetBrains Mono**
- 크기: 표지 제목 48 · 본문 제목 30 · 소제목 14~18 · 본문 12~13 · 설명 10.5~11.5 · 라벨·태그 10.5~11 · 바닥글 9

## 캔버스와 격자 (LAYOUT_WIDE 13.33 × 7.5 in)

```
y 0.32  섹션 라벨 (보라 11pt bold)            x 0.6
y 0.62  태그 알약 (0.3 높이)                    x 0.6
y 0.95  제목 (30pt, 왼쪽 정렬, 높이 0.75)      x 0.6  w 9.5
y 1.68  부제 (13pt 회보라)                      x 0.6  w 9.5
y 2.2 ~ 6.7  본문 영역                          x 0.6 ~ 12.7 (너비 12.1)
y 7.0   바닥글(왼쪽) · 쪽번호(오른쪽 12.3)
```

- 좌우 여백 0.6. 본문 두 단은 왼쪽 7.3 + 간격 0.4 + 오른쪽 4.45 (= 8.3부터), 세 단은 3.9씩 간격 0.2, 다섯 단은 2.25씩 간격 0.2.
- 버전·트랙 뱃지는 제목 줄 오른쪽 끝 (x 11.9, y 1.1).
- 표지(TITLE 레이아웃): 왼쪽에 알약(0.8, 0.9) → 제목 2줄(48pt) → 부제 → 아이콘 타일 4개(y 5.5). 오른쪽 x 9.0에 폰 목업(3.0 × 5.6) 또는 사진 카드.

## 모티프 (deck.js 함수)

| 모티프 | 함수 | 쓰는 곳 |
|---|---|---|
| 섹션 라벨 + 태그 알약 | `slide({label, tag})` | 모든 본문 슬라이드. 라벨은 "① 배선", "시작 · 오늘의 지도"처럼 단원, 태그는 "따라 하기"(진남색) / "실습 · 20분"(보라) |
| 번호 원 + 한 줄 | `step` | 따라 하는 순서 3~5개 |
| 흰 카드 | `card`, `imageCard`, `iconTile` | 내용 묶음, 스크린샷·배선도 |
| 큰 숫자 카드 "01" | `numberCard` | 걸음·선택지·결과 나열. 마지막 또는 강조 하나만 `filled` |
| 진남색 코드 바 | `codeBar` | 코드·시리얼 출력. 1줄이면 높이 0.55, n줄이면 0.35 + 0.3n |
| 명령어 칩 | `chip` | 짧은 명령·키워드 목록 (칩 + 설명 한 줄) |
| 연보라 콜아웃 | `callout` | 주의·도전·한 줄 결론. 슬라이드 맨 아래 폭 전체 |
| 채움 배너 | `banner` | 주황 = "바로 손 든다" 류 강한 주의, 보라 = 마무리 결론 |
| 경고 상자 | `warnBox` | 안전·고장 위험 (빨간 계열) |
| 체크 행 | `checkRow` | 확인 항목 |
| 표 | `table` | 시간표·규칙표. 헤더 진남색, 줄무늬 흰/연보라, 테두리는 배경색 |
| 폰 목업 | `phoneMock` | 표지·앱 화면 |

## 하지 말 것

- 어두운 배경 슬라이드, 그라데이션, 그림자, 색 띠(스트라이프) 모티프
- 제목 가운데 정렬 (왼쪽 정렬이 이 디자인의 특징)
- 주황을 두 군데 이상, 보라 채움 카드를 두 장 이상 한 슬라이드에
- 글머리표 문자 `•`를 직접 타이핑 (pptxgenjs `bullet: true` 사용)
- 본문 글자 10pt 미만
