# 우산 보관함 배선표 — 서보모터 4개 + 리드센서 4개

보관함 슬롯 4칸짜리 기준 배선입니다. (DB의 L001 보관함 = 슬롯 4칸)

- **서보모터 (SG90 등) ×4** — 슬롯 잠금장치 (열림/잠김)
- **리드센서(리드 스위치) ×4** — 우산 거치 감지 (우산·문에 자석 부착)

> 🧭 보드: **Wemos D1 R32** 기준. 보드에 인쇄된 라벨(D2, D9…)과 코드의 GPIO 번호는 다릅니다!
> → [`../../01_docs/pinmap_wemos_d1_r32.md`](../../01_docs/pinmap_wemos_d1_r32.md)

## 전체 배선표

| 부품 | 선 | ESP32 GPIO (코드) | 보드 라벨 | 비고 |
|---|---|:---:|:---:|---|
| 서보 1 (슬롯1) | 신호(주황) | **GPIO16** | D5 | |
| 서보 2 (슬롯2) | 신호(주황) | **GPIO17** | D4 | |
| 서보 3 (슬롯3) | 신호(주황) | **GPIO25** | D3 | |
| 서보 4 (슬롯4) | 신호(주황) | **GPIO26** | D2 | |
| 서보 공통 | VCC(빨강) | — | — | ⚠ **외부 5V** (아래 전원 주의 참고) |
| 서보 공통 | GND(갈색) | — | GND | 외부 전원 GND와 **공통 접지** |
| 리드센서 1 (슬롯1) | 한쪽 다리 | **GPIO13** | D9 | `INPUT_PULLUP` |
| 리드센서 2 (슬롯2) | 한쪽 다리 | **GPIO14** | D7 | `INPUT_PULLUP` |
| 리드센서 3 (슬롯3) | 한쪽 다리 | **GPIO27** | D6 | `INPUT_PULLUP` |
| 리드센서 4 (슬롯4) | 한쪽 다리 | **GPIO4** | A1 | `INPUT_PULLUP` (아날로그 자리지만 디지털 입력으로 사용) |
| 리드센서 공통 | 반대쪽 다리 | — | GND | 4개 모두 GND로 |

RFID(RC522)를 함께 쓰는 팀은 **GPIO27(D6)이 RC522 RST와 겹치니** 리드센서 3번만
GPIO21(SDA 핀)로 옮겨 점퍼선으로 배선하세요 (센서쉴드 없이 직접 배선하는 경우):

| RC522 | GPIO | 보드 라벨 |
|---|:---:|:---:|
| SDA(SS) | GPIO5 | D10 |
| SCK | GPIO18 | D13 |
| MOSI | GPIO23 | D11 |
| MISO | GPIO19 | D12 |
| RST | GPIO27 | D6 |
| 3.3V / GND | — | 3.3V / GND (**5V 금지!**) |

## 코드용 핀 정의 (복사해서 쓰세요)

```cpp
// ── 서보 (슬롯 잠금) ──
const int SERVO_PIN[4] = { 16, 17, 25, 26 };   // 슬롯 1~4

// ── 리드센서 (우산 거치 감지) ──
const int REED_PIN[4]  = { 13, 14, 27, 4 };    // 슬롯 1~4

void setup() {
  for (int i = 0; i < 4; i++) pinMode(REED_PIN[i], INPUT_PULLUP);
  // 자석 가까이(우산 있음/문 닫힘) → LOW, 자석 멀어짐 → HIGH
}
```

서보 제어는 `ESP32Servo` 라이브러리를 쓰세요 (라이브러리 매니저에서 "ESP32Servo" 검색 → Kevin Harrington).
기본 `Servo.h`는 ESP32에서 동작하지 않습니다.

```cpp
#include <ESP32Servo.h>
Servo servo[4];
// setup(): servo[i].attach(SERVO_PIN[i]);
// 열기: servo[i].write(0);  잠그기: servo[i].write(180);  (방향이 반대면 두 값을 서로 바꾸세요)
```

## 아두이노 센서쉴드를 꽂아서 쓰는 경우

센서쉴드(V5형)를 D1 R32에 꽂으면 핀마다 **G-V-S 3핀 헤더**가 생겨 배선이 훨씬 쉬워집니다.
실드에 인쇄된 숫자는 **우노 라벨**이라, 위 표의 "보드 라벨"에서 D를 뺀 숫자 자리에 꽂으면 됩니다:

| 부품 | 실드에 꽂는 자리 | GPIO (코드) |
|---|:---:|:---:|
| 서보 1~4 | **5 · 4 · 3 · 2** | 16 · 17 · 25 · 26 |
| 리드스위치 1~4 | **9 · 7 · 6 · A1** | 13 · 14 · 27 · 4 |

- **서보**: 3핀 케이블을 그대로 꽂기 — 주황(신호)=S, 빨강=V, 갈색=G 방향 확인!
- **리드스위치**: S와 G에만 연결 (V는 사용 안 함 — 코드가 내부 풀업을 켭니다)
- **A1 자리(GPIO4)**: 아날로그 헤더지만 여기서는 **디지털 입력**으로 씁니다.
  "A1은 WiFi와 같이 못 쓴다"는 규칙은 analogRead 얘기라 리드스위치(digitalRead)는 문제없어요.
  (A2~A5는 내부 풀업이 없어서 리드스위치에 못 쓰니 A1이어야 합니다!)
- ⚠ 실드의 V줄은 기본적으로 보드 전원과 연결돼 있어요. 서보 4개를 돌리려면
  **실드의 외부 전원 단자(EXT PWR)에 5V를 넣고 전원 선택 점퍼를 외부로** 바꾸세요.
  외부 전원 단자가 없는 실드라면 서보 빨간 선만 따로 외부 5V에 묶고 GND를 공통으로.

## ⚠ 전원 주의 — 서보는 반드시 외부 5V!

```
외부 5V (건전지 4개 팩 또는 5V 2A 어댑터)
   ├── 서보 4개 VCC(빨강)
   └── GND ──┬── 서보 4개 GND(갈색)
             └── ESP32 GND  ← ★ 반드시 연결(공통 접지)
```

- 서보 4개가 동시에 움직이면 순간 전류가 **2A 이상** 튑니다.
  보드의 3.3V/5V 핀에서 끌어오면 **보드가 리셋되거나 WiFi가 끊깁니다.**
- 외부 전원의 GND와 ESP32의 GND를 **꼭 연결**해야 서보가 신호를 알아듣습니다.
- 리드센서는 전원이 필요 없습니다(그냥 스위치) — GPIO와 GND에만 연결.

## ❌ 12V 어댑터를 써도 되나요? (보드 DC잭 / 실드 EXT PWR 둘 다)

**꽂지 마세요. 서보가 타버릴 수 있습니다.**

> ⚠ **"보드 말고 실드에 꽂으면 되나요?" → 아닙니다. 더 위험합니다.**
> 핵심은 **어디에 꽂느냐가 아니라 몇 V냐**입니다.
> 실드의 외부 전원 단자에는 **전압을 낮춰주는 부품이 없습니다.** 넣은 전압이
> V줄로 그대로 나가므로, 12V를 넣으면 서보 4개에 12V가 곧장 걸립니다.
>
> | 어디에 | 12V | 5V |
> |---|:---:|:---:|
> | 보드 DC잭 | ❌ 서보 손상 위험 | ⭕ |
> | 실드 EXT PWR | ❌❌ **서보에 직행** | ⭕ 정답 |
>
> → **12V는 어디에도 꽂지 마세요.** 5V로 낮춘 뒤 실드 EXT PWR에 넣는 것이 맞습니다.

이유는 전압이 아니라 **그 12V가 어디로 흘러가느냐**입니다.

```
12V 어댑터 → 보드 DC잭 → [레귤레이터] → 3.3V (ESP32는 OK)
                     └──→ 5V 핀 / 실드 V줄 → 서보 ← ⚠ 여기로 12V가 그대로!
```

D1 R32와 센서쉴드는 **DC잭 입력이 5V 핀·실드 V줄로 거의 그대로 나오는 구조가 많습니다.**
그 자리에 서보를 꽂으면 **4.8~6V짜리 서보에 12V가 걸려 즉시 망가집니다.**

그 밖에도:
- 보드의 레귤레이터는 12V를 3.3V로 낮추며 **열로 태워 없앱니다.** 뜨거워지고, 심하면 보호 차단·고장
- **5A는 어차피 못 씁니다.** 보드 레귤레이터가 통과시킬 수 있는 건 수백 mA 수준이에요

### 그럼 어떻게 하나요

**가장 좋은 방법 — 5V 어댑터를 따로 준비**

```
5V 2~3A 어댑터
   ├── 서보 4개 VCC(빨강)   ← 서보는 여기서 직접
   └── GND ──┬── 서보 4개 GND(갈색)
             └── 보드 GND     ← ★ 공통 접지
보드는 USB로 따로 전원 (또는 같은 5V를 보드 5V 핀에)
```

**12V 어댑터밖에 없다면 — 벅 컨버터로 낮춰서**

`LM2596` 같은 **DC-DC 스텝다운 모듈**(12V→5V, 3A 이상)을 하나 끼우세요.

```
12V 5A 어댑터 → [벅 컨버터 12V→5V] → 5V ─┬── 실드 EXT PWR (전원 점퍼 = 외부)
                                          └── 보드 GND (공통 접지)
```

1. 어댑터 → 벅 컨버터 입력(IN+ / IN−)
2. **서보를 아직 꽂지 말고** 컨버터 출력(OUT+ / OUT−)을 멀티미터로 측정
3. 가변저항을 돌려 **5.0V**를 맞춘 뒤
4. 그제서야 출력을 실드 EXT PWR에 연결

### 서보를 꽂기 전에 꼭 재보세요

보드·실드마다 배선 구조가 달라서, **직접 재보는 게 유일하게 확실한 방법**입니다.

1. 서보를 **모두 뽑은 상태**로 전원을 연결
2. 멀티미터로 **실드 V핀 ↔ G핀** 전압 측정
3. **4.8~6.0V가 나오면 OK**, 그보다 높으면 절대 서보를 꽂지 마세요

## 리드센서 동작 원리

```
자석이 가까이 오면 → 스위치 닫힘(GPIO-GND 연결) → digitalRead = LOW  → "우산 있음"
자석이 멀어지면   → 스위치 열림               → digitalRead = HIGH → "우산 없음"
```

우산 손잡이(또는 슬롯 문)에 자석을 붙이고, 리드센서는 거치대 쪽에 고정하세요.
감지 거리가 짧으니(보통 1cm 안팎) 자석과 센서 위치를 먼저 맞춰보고 고정!

## 피해야 할 핀 (참고)

| 핀 | 이유 |
|---|---|
| GPIO12 (D8) | 부팅 시 상태 민감 — 여기에 뭔가 달면 업로드/부팅이 실패할 수 있음 |
| GPIO34·35·36·39 (A2~A5) | **입력 전용 + 내부 풀업 없음** — 서보 불가, 리드센서를 쓰려면 외부 저항(10kΩ) 필요 |
| GPIO1·3 (TX0·RX0) | USB 시리얼과 공유 — 사용 금지 |
| GPIO2 (A0) | 내장 LED와 공유 — 상태 표시용으로 비워두기 |

> 💡 7세그(TM1637)를 같이 쓰고 싶은 팀은 GPIO14(D7)·GPIO27(D6)이 수업 기본 7세그 핀과 겹칩니다.
> 그 경우 7세그 DIO·CLK를 비어 있는 GPIO21·22(SDA·SCL 핀)에 점퍼선으로 배선하세요.
