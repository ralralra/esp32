# 4단계 프롬프트 — 관리자(사장님) 앱

> AI Studio에서 **새 앱**으로 생성하세요 (손님 앱과 별개).
> `배포URL` 자리에 내 Apps Script 배포 URL을 바꿔 넣으세요.

## AI Studio Build에 붙여넣기

```
카페 "푸메콥스"의 관리자용 매출 대시보드 웹앱을 만들어줘.

[데이터]
- 아래 주소로 fetch GET 요청을 보내면 매출 집계 JSON이 온다:
  배포URL?action=sales
- 응답 형태:
  { "orders": 총 주문 수, "revenue": 총매출,
    "top": [ { "name": 메뉴명, "count": 판매수 }, ... ],
    "recent": [ { "no": 주문번호, "items": 내역, "total": 합계, "time": 시각 }, ... ] }

[화면 구성]
- 상단: "푸메콥스 관리자" 제목과 [새로고침] 버튼
- 요약 카드 3개: 총 주문 수 / 총 매출(원) / 평균 주문 금액(총매출 ÷ 주문 수)
- "인기 메뉴 TOP 5" — 1~5위 순위 목록 (1위는 강조)
- "최근 주문" — 주문번호·내역·합계·시각 목록

[디자인 규칙]
- 남색 헤더에 밝은 배경, 흰색 카드, 파란색 포인트, 모바일 우선, 큰 숫자
- 손님 앱과 같은 계열의 디자인으로 통일감 있게

[동작 규칙]
- 앱을 열면 자동으로 데이터를 불러오고, [새로고침]을 누르면 다시 불러온다
- 주문이 하나도 없으면 "아직 주문이 없어요"를 보여준다
- 로그인 기능은 만들지 마
```

## 점검
- 숫자가 안 나오면: 브라우저로 `배포URL?action=sales` 를 직접 열어 JSON 확인
- 평균 주문 금액이 이상하면: "주문이 0건일 때는 평균을 0으로 표시해줘" 추가 지시
