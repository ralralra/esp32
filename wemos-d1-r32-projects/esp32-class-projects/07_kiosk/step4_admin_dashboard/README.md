# 4단계 — 관리자(사장님) 대시보드 앱 (완성본) 🎉

## 목표
DB에 쌓인 매출 데이터로 **관리자 앱**을 만든다 — 총 주문 수·총매출·인기 메뉴 TOP 5·최근 주문.

## 두 개의 앱
```
손님 앱(키오스크):  메뉴 선택 → 가상 결제 → DB 저장   (1~3단계에서 완성)
관리자 앱(사장님):  DB 읽기 → 매출·인기메뉴·최근주문    (이번 단계, AI Studio로 새로 생성)
```
같은 DB(주문로그 시트)를 손님 앱은 **쓰고**, 관리자 앱은 **읽어요.**

## 핵심 — 집계는 서버가
[`kiosk_db.gs`](kiosk_db.gs) 의 `sales()` 가 주문로그를 한 줄씩 읽어 합계·순위를 계산해 JSON으로 응답합니다.
```
for (각 주문줄) { revenue += 합계;  내역의 각 메뉴 count++; }
```
6회차에서 배운 통계(엑셀 COUNTIF의 코드 버전)와 같은 원리예요.

## 해보기
1. Apps Script 코드를 [`kiosk_db.gs`](kiosk_db.gs)(완성본)로 교체 → **새 배포**
2. 브라우저로 `배포URL?action=sales` 열기 → 집계 JSON이 보이면 서버 완성
3. [`프롬프트.md`](프롬프트.md) 로 AI Studio에서 **관리자 앱**을 새로 생성 (URL 넣기)
4. 손님 앱에서 여러 번 주문 → 관리자 앱 [새로고침] → 숫자가 늘어나는지 확인
5. 시트를 직접 열어 집계가 실제 데이터와 맞는지 검산

## 확인 ✅
- [ ] 총 주문 수·총매출이 시트 내용과 일치한다
- [ ] 인기 메뉴 TOP 5 순위가 맞다
- [ ] 최근 주문 목록에 방금 주문이 나타난다
- [ ] 주문할수록 관리자 앱 숫자가 늘어난다

## 배운 것 (키오스크 전체 정리)
1. AI Studio로 손님 앱 화면 만들기 (앱 전용, 하드웨어 없음)
2. 가상 결제 연출 — 실결제 없이 결제 흐름 체험
3. 주문(매출) 데이터를 DB(구글 시트)에 저장
4. 같은 DB를 읽는 관리자 앱으로 매출 집계

## 확장 아이디어
- 인기 메뉴 1위 강조, 시간대별 매출 그래프
- 메뉴 관리 화면 (시트의 메뉴 탭을 읽어 손님 앱 메뉴 자동 갱신)
- 품절 처리 (메뉴 탭에 '판매중/품절' 열 추가)
- 주문 상태 관리 (접수 → 준비중 → 완료, 시트에 상태 열 추가)
- 일별 매출 비교 (시각 열을 날짜별로 집계)

센서·하드웨어 없이 앱과 DB만으로 완성했어요. 👏
