# 3단계 프롬프트 — 앱과 DB 연결

> `배포URL` 자리에 **내 Apps Script 배포 URL**(`/exec`로 끝남)을 꼭 바꿔 넣으세요.

## AI Studio에 추가 지시

```
결제 연출의 "승인 중입니다..." 단계에서 주문을 서버에 저장하도록 연결해줘.

[연결 규칙]
- 승인 중 화면일 때 아래 주소로 fetch GET 요청을 보낸다:
  배포URL?action=order&items=(장바구니)&total=(합계)
- items 는 장바구니를 "메뉴명(옵션):가격" 형태로 만들고 | 로 연결한다.
  예: 아메리카노(핫):1500|레몬티(아이스):1500  (URL 인코딩해서 보내기)
- 서버가 회신한 숫자가 진짜 주문번호야. 결제 완료 화면에는 이 번호를 크게 표시해줘.
  (앱이 스스로 세던 주문번호는 이제 쓰지 마)
- 요청이 실패하면 "주문 저장에 실패했어요. 직원을 불러주세요"를 보여주고 장바구니는 유지해줘.
```

## 점검
- 앱 주문 → 시트에 줄이 안 생기면: 브라우저 주소창으로 `배포URL?action=order&items=테스트:1000&total=1000` 을 직접 열기
  - 시트에 줄이 생김 → 서버 정상, 앱에 넣은 URL 오타
  - 안 생김 → Apps Script **새 배포**를 했는지, 액세스가 '모든 사용자'인지 확인
