# 2단계 프롬프트 — 가상 결제 연출 추가

> 1단계 앱이 열려 있는 AI Studio 대화에 **이어서** 붙여넣으세요.

## AI Studio에 추가 지시

```
[주문하기] 버튼에 가상 결제 연출을 추가해줘. 실제 결제는 절대 아니고 화면 연출만이야.

[결제 연출 순서]
1. [주문하기]를 누르면 전체 화면 안내가 뜬다: 💳 큰 아이콘과 "카드를 리더기에 대주세요"
   (2초 후 자동으로 다음 장면)
2. "승인 중입니다..." 문구와 로딩 애니메이션 (1.5초 후 자동으로 다음 장면)
3. 결제 완료 화면: ✅ "결제 완료!" + 크게 표시된 주문번호 + 주문 내역 영수증(메뉴·옵션·가격 목록과 합계)
   + [처음으로] 버튼

[동작 규칙]
- 주문번호는 1번부터 시작해서 주문할 때마다 1씩 커진다 (브라우저에 저장해서 새로고침해도 유지)
- [처음으로]를 누르면 장바구니를 비우고 첫 화면으로 돌아간다
- 카드번호 입력, 실제 결제 연동 기능은 절대 만들지 마
```

## 점검
- 연출 장면이 너무 빠르거나 느리면: "카드 안내 화면을 3초로 늘려줘"처럼 **하나씩** 조정
- 완료 화면이 허전하면: "영수증에 주문 시각도 보여줘" 등 추가 지시
