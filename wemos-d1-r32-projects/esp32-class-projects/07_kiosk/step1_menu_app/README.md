# 1단계 — AI Studio로 손님 앱(키오스크 화면) 만들기

## 목표
AI Studio로 **손님용 키오스크 앱 1차 버전**을 만든다.
메뉴를 고르고 핫/아이스를 선택해 장바구니에 담고, 합계까지 보이면 성공. (결제는 2단계)

## 왜 AI Studio?
5회차에서 배운 방식 그대로예요 — **스케치를 '말'로 번역하면 AI가 '화면'으로 번역**해 줍니다.
AI Studio 사용법·폰 설치(PWA)는 [`01_docs/ai_studio_webapp_guide.md`](../../01_docs/ai_studio_webapp_guide.md) 참고.

## 해보기
1. 화면을 종이에 먼저 스케치 — 상단 로고 / 메뉴 카드 / 핫·아이스 선택 / 장바구니·합계 / [주문하기]
2. [`프롬프트.md`](프롬프트.md) 를 우리 가게에 맞게 고치기 (가게 이름·메뉴·가격)
3. AI Studio Build에 프롬프트 붙여넣고 생성
4. 스케치와 비교 — 빠진 요소·이상한 부분을 **하나씩** 추가 지시로 고치기
5. 메뉴를 눌러 장바구니에 쌓이고 합계가 오르는지 확인

## 확인 ✅
- [ ] 메뉴 카드가 보이고, 누르면 장바구니에 담긴다
- [ ] 핫/아이스를 선택해서 담을 수 있다
- [ ] 장바구니에서 항목을 삭제할 수 있다
- [ ] 합계가 맞게 계산된다

## 배운 것
- 키오스크 = 메뉴 선택 → 장바구니 → 결제 흐름
- 스케치의 모든 요소를 프롬프트 문장에 담으면 AI가 화면을 만들어 준다
- **하드웨어 없이** 앱만으로 시작 — 화면 먼저, 저장(DB)은 나중에
