# 1단계 프롬프트 — 손님 앱 1차 버전

> 5회차에서 배운 **좋은 프롬프트 4요소**(한 문장 → 화면 요소 → 디자인 규칙 → 동작 규칙) 그대로예요.
> `푸메콥스`와 메뉴·가격은 **우리 가게 것으로 바꿔서** 사용하세요.

## AI Studio Build에 붙여넣기

```
카페 "푸메콥스"의 무인 키오스크 웹앱을 만들어줘.

[화면 구성]
- 상단: ☕ 로고와 가게 이름 "푸메콥스"
- 제목: "음료를 선택해주세요", 부제목: "원하시는 메뉴를 터치해 주세요"
- 메뉴 카드 6개를 3열 격자로: 아메리카노 1,500원 / 초코라떼 2,000원 / 매실 1,500원 /
  오미자 1,500원 / 미숫가루 2,000원 / 레몬티 1,500원 (각 카드에 어울리는 이모지 크게)
- 메뉴 아래: "아이스 / 핫을 선택해주세요" — 큰 버튼 2개(☕ 핫 / 🧊 아이스), 선택된 쪽에 체크 표시
- 하단: 장바구니 목록(메뉴명·옵션·가격, 항목별 ✕ 삭제 버튼), 합계 금액, 큰 [주문하기] 버튼

[디자인 규칙]
- 밝은 회색 배경에 흰색 카드, 남색·파란색 포인트, 모바일(세로) 우선, 버튼 크게, 큰 글씨
- 태블릿에 세워두면 진짜 키오스크처럼 보이게

[동작 규칙]
- 메뉴 카드를 누르면 현재 선택된 핫/아이스 옵션과 함께 장바구니에 담긴다
- 장바구니에 담길 때마다 합계가 다시 계산된다
- 장바구니가 비어 있을 때 [주문하기]를 누르면 "메뉴를 담아주세요" 안내를 보여준다
- 결제·로그인 기능은 아직 만들지 마 (다음 단계에서 추가)
```

## 생성 후 점검 (스케치와 나란히 비교)
- 빠진 요소·다른 배치를 목록으로 적고, **하나씩** 추가 지시로 해소
- 과한 기능(회원가입 등)이 생겼으면 "○○ 기능은 빼줘"라고 삭제 요청 — 범위 지키기!
