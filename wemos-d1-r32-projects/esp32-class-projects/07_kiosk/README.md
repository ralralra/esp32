# 스마트 창업 키오스크 (푸메콥스 카페) ☕

카페 음료를 파는 **무인 키오스크 앱**입니다. 폰/태블릿 화면에서 메뉴를 골라 담고,
**가상으로 결제하는 것처럼 연출**한 뒤, 주문(매출) 데이터가 **DB(구글 시트)** 에 저장·집계됩니다. (창업 교육 연계)

## 무엇을 만드나

```
손님 앱(키오스크)                                DB(구글 시트)
 메뉴 선택 → 장바구니 → 가상 결제 ──▶ Apps Script ──▶ 주문로그 저장
                                          │
관리자 앱(사장님) ◀── 총매출·인기메뉴·최근주문 ──┘
```

- **하드웨어·센서 없음** — ESP32·부품 없이 브라우저(폰·태블릿·PC)만으로 완성
- **실제 돈 안 씀** — 결제는 "카드를 대주세요 → 승인 중 → 완료" **화면 연출만** (기획서 원칙)
- **DB 저장** — 모든 주문이 구글 시트(주문로그)에 쌓이고, 관리자 앱에서 집계

## 단계 안내

| 단계 | 폴더 | 무엇을 / 확인 |
|---|---|---|
| 1 | `step1_menu_app` | 손님 앱 화면 (메뉴·핫/아이스·장바구니) — **AI Studio로 생성** |
| 2 | `step2_virtual_pay` | 가상 결제 연출 + 주문번호 발급 — AI Studio 추가 지시 |
| 3 | `step3_save_db` | 주문을 DB(구글 시트)에 저장 — Apps Script 연결 |
| 4 | `step4_admin_dashboard` | 관리자 앱 — 매출·인기메뉴 대시보드 (완성) |

> "화면 먼저 → 저장은 나중에" 흐름이에요. 앱은 5회차에서 배운 **AI Studio 프롬프트** 방식으로 만들고
> ([`01_docs/ai_studio_webapp_guide.md`](../01_docs/ai_studio_webapp_guide.md)),
> 시트+Apps Script 연결은 [4회차 — 클라우드 확장](../02_sessions/04_cloud_expansion/README.md)에서 배운 그대로!

## 준비물
- PC 또는 폰/태블릿 (태블릿이 더 키오스크답습니다)
- 구글 계정 (AI Studio + 시트 + Apps Script)
- **보드·센서·배선 없음!**

## 매점 프로젝트와의 관계
- 매점(`05_store/`) = RFID로 **계산원 없는 셀프 계산** (하드웨어 사용)
- 키오스크(`07_kiosk/`) = 화면으로 **메뉴 선택 + 가상 결제 + DB 매출 저장** (앱 전용)
- 데이터 구조(메뉴·주문로그)가 비슷해서 한 팀이 묶어서 하기 좋아요
