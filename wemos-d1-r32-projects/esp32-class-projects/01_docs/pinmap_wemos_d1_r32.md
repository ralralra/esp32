# Wemos D1 R32 핀맵 — 보드 라벨 vs GPIO 번호

> ⚠️ **가장 중요한 규칙**: 보드에 인쇄된 이름(D2, A0 …)과
> **코드에서 쓰는 GPIO 번호는 다릅니다.**
> 코드는 언제나 **GPIO 번호** 기준이에요. 이 표를 항상 옆에 두세요.
>
> 보드 핀맵 사진: [`wemosD1R32 pinmap.jpg`](<../images/wemosD1R32 pinmap.jpg>)

![Wemos D1 R32 핀맵](<../images/wemosD1R32 pinmap.jpg>)

센서는 **암-수 점퍼선**으로 D1 R32 헤더 핀에 직접 연결해요.
센서의 G·V·S(또는 GND·VCC·신호) 핀을 점퍼선 3가닥으로 이어 주면 됩니다.

- **G → GND**, **V → 3V3**, **S → 신호 핀** (아래 표의 보드 라벨 위치)
- 보드에 따라 헤더에 D6 같은 라벨 대신 IO27 같은 GPIO 번호가 인쇄돼 있기도 해요. 어느 쪽이든 아래 표로 맞춰 보면 됩니다.

## 아날로그 (Analog) 헤더

| 보드 라벨 | GPIO | ADC | WiFi와 같이 써도 되나? | 메모 |
|:---:|:---:|:---:|:---:|---|
| A0 | GPIO2 | ADC2 | ❌ **불가** | 내장 LED와 공유 |
| A1 | GPIO4 | ADC2 | ❌ **불가** | |
| **A2** | **GPIO35** | ADC1 | ✅ 가능 | 입력 전용 |
| **A3** | **GPIO34** | ADC1 | ✅ 가능 | 입력 전용 |
| **A4** | **GPIO36** | ADC1 | ✅ 가능 | 입력 전용 (SVP) |
| **A5** | **GPIO39** | ADC1 | ✅ 가능 | 입력 전용 (SVN) |

> 🔑 **아날로그 센서는 A2~A5 핀에!**
> ESP32의 ADC2(A0·A1 핀)는 **WiFi를 켜면 아날로그 읽기가 멈춥니다.**
> 3회차부터는 WiFi를 항상 쓰니까, 처음부터 A2~A5(GPIO 34·35·36·39)에 연결하는 습관을 들여요.
> (34·35·36·39는 **입력 전용** — 출력(digitalWrite)은 안 됩니다)

|:---:|:---:|:---|---|
| D2 | GPIO26 | DAC2 | 범용 (예: 릴레이) |
| D3 | GPIO25 | DAC1 | 범용 |
| D4 | GPIO17 | U2-TX | 범용 |
| D5 | GPIO16 | U2-RX | 범용 |
| D6 | GPIO27 | | 범용 |
| D7 | GPIO14 | | 범용 |
| D8 | GPIO12 | | ⚠ 부팅 시 상태 민감 — 가급적 비우기 |
| D9 | GPIO13 | | 범용 |

## I2C (SDA·SCL)

| 보드 라벨 | GPIO | 용도 |
|:---:|:---:|---|
| SDA | GPIO21 | I2C 데이터 |
| SCL | GPIO22 | I2C 클럭 |

> ⚠ **본 과정은 LCD(I2C)를 사용하지 않아요** — 숫자 표시는 7세그(TM1637)!
> I2C 모듈을 쓸 때는 SDA → **SDA 핀(GPIO21)**, SCL → **SCL 핀(GPIO22)** 에 점퍼선으로 직접 연결하면 됩니다.
> (우노의 A4·A5 자리는 D1 R32에서 GPIO36·39 입력 전용이라 I2C로 쓸 수 없어요.)

## 그 밖에 기억할 것

- **내장 LED = GPIO2** (파란색) — 모든 실습의 "동작 확인용 신호등"
- **내장 버튼**: EN(리셋), IO0(BOOT — 업로드가 `Connecting...`에서 멈출 때만 사용)
- 동작 전압 **3.3V** — 핀에 5V를 직접 넣지 마세요
  - 아날로그 센서(빛·소리·토양습도 등)의 V는 **반드시 3V3** — 출력이 3.3V를 넘으면 ESP32 입력이 상할 수 있어요
  - 디지털 센서(진동·홀·DHT)·7세그(TM1637)도 **3V3** 권장
  - 센서를 여러 개 쓸 때: 보드의 **3V3 핀은 하나**뿐이에요 → **미니 브레드보드**에 3V3·GND를 한 번 끌어온 뒤 센서마다 나눠 연결해요 (GND 핀은 보드에 여러 개 있어요)
  - 5V 전용 초음파 모듈(HC-SR04 등)은 ECHO 출력이 5V → **분압 저항(1kΩ 직렬 + 2kΩ to GND)** 을 거쳐 ESP32 핀에 연결
- 점퍼선을 꽂은 **보드 라벨(D6) ↔ 코드 GPIO(27)** 를 위 표로 꼭 맞춰 보세요

## 수업에서 자주 쓰는 핀 정리 (빠른 참조)

| 용도 | GPIO | 위치 |
|---|:---:|---|
| 내장 LED | 2 | 보드 내장 |
| 빛·토양습도 등 아날로그 센서 | 34 (또는 35·36·39) | A3 (또는 A2·A4·A5) |
| 7세그 DIO·CLK | 27 · 14 | D6 · D7 |
| 진동·홀 등 디지털 센서 | 27 등 | 디지털 핀 아무 곳 (예: D6) |
| 릴레이 (화분 펌프) | 26 | D2 |
| 초음파 TRIG / ECHO | 27 · 14 | D6 · D7 (5V 모듈이면 ECHO에 분압 저항) |
