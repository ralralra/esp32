# 교육지도서 슬라이드

`smart_attendance_teaching_guide.pptx` — 스마트 출석체크 시스템의 제작·연동 전 과정을 담은
30장 분량 교육용 슬라이드입니다. 수업 진행과 교재(책) 원고 작성 모두를 염두에 두고 만들었습니다.

## 구성

| 슬라이드 | 내용 |
|---|---|
| 1~3 | 표지 · 학습 목표와 4차시 구성 · 완성된 시스템의 세 장면 |
| 4~6 | 개념 — RFID/NFC 원리 · 시스템 구조(왜 중계 서버인가) · 출석체크 전체 흐름 6단계 |
| 7~8 | 1차시 — 준비물 체크리스트 · RC522 배선(배선도 포함) |
| 9~10 | 2차시 — `uid_test`의 `setup()` 자가진단, `loop()` UID 읽기 |
| 11 | 개념 — 세션과 폴링(타임라인 예시) |
| 12~20 | 3차시 — 시트 DB 구성 · GAS 배포 · `relay.gs` 함수별 해설 7장 |
| 21~25 | 4차시 — 완성 펌웨어 함수별 해설 5장 |
| 26~27 | 4차시 — 앱 제작(프롬프트)과 앱 연동 코드 |
| 28~30 | 정리 — 통신 규칙 표 · 테스트/트러블슈팅 · 확장 아이디어 |

## 특징

- **코드는 함수 단위로 분할** — 한 슬라이드에 한 함수, 왼쪽 설명 + 오른쪽 코드 구성
- **모든 코드 슬라이드에 원본 코드 주소 표기** — 슬라이드의 코드는 이해를 위한 요약본이며,
  전체 코드는 하단 주소(저장소 링크)에서 확인
- **발표자 노트(speaker notes)** — 슬라이드마다 지도 시 유의점, 비유, 발문, 자주 나오는 실수를
  기록해 두었습니다. 책 원고를 쓸 때 해설 문단의 초안으로 쓸 수 있습니다

## 다시 만들기 / 수정하기

`build_deck.js`가 이 슬라이드를 생성한 스크립트입니다.

```bash
npm install pptxgenjs
node build_deck.js
```

색상·문구·슬라이드 순서를 바꾸려면 이 스크립트를 수정하고 다시 실행하세요.
배선도 이미지는 `../images/rc522_wemos_d1_r32_wiring.png` 를 참조합니다.
