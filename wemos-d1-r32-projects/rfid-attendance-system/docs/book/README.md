## 원고의 특징

**코드는 함수 단위로 다룹니다.** 한 절에 한 함수를 놓고 "왜 필요한가 → 무엇을 하는가 → 어떻게 하는가" 순으로 서술합니다. 각 코드 조각에는 저장소의 원본 파일 주소를 함께 적었습니다.

**실제 겪은 문제를 그대로 담았습니다.** 학생증이 인식되지 않던 문제(6.2절), 앱 연동 후 LED가 멈추고 태그를 놓치던 문제(14.1절)를 진단 과정과 함께 서술했습니다. 매끄러운 성공담보다 교육 효과가 큽니다.

**교사용 요소를 본문에 녹였습니다.**
- `💡 수업 활용 팁` — 비유, 발문, 역할극 등 지도 방법
- `📌 짚고 넘어가기` — 개념 보충과 배경 설명
- 각 장 끝의 **정리 / 실습 과제 / 생각해 볼 문제**
- 부록 C에 4차시 운영 예시와 평가 기준

## 조판·편집 시 참고

- 원고는 마크다운입니다. Pandoc 등으로 DOCX·PDF·InDesign 원고로 변환할 수 있습니다.
  ```bash
  pandoc 0*.md 1*.md ... -o book.docx
  ```
- 본문에 삽입할 그림: `../images/rc522_wemos_d1_r32_wiring.png` (5장 배선도)
- 앱 화면 캡처(1장 세 장면), 시리얼 모니터 캡처(6장), 시트 캡처(8장)는 실물 촬영본으로 채우면 좋습니다.
- 슬라이드(`../slides/`)의 도해를 그대로 도판으로 쓸 수 있습니다 — 3장 구조도, 3.4절 흐름도, 7.3절 폴링 비교표.
